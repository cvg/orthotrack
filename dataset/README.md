# Supported Datasets

- **[MovingDrone](movingdrone.md)** — primary benchmark (download published scenes; local layout `data/MovingDrone/scenes/`). Bundled scenes ship **0.2 m/px** DOP/DSM priors.
- **[UAVD4L](uavd4l.md)** — external dataset; run OrthoTrack like custom footage + DOP/DSM.
- **[UAVScenes](uavscenes.md)** — external dataset; same custom-data path once you have DOP/DSM coverage.

For map quality guidelines (GSD, coverage, intrinsics), see **Best practices** in the root [README](../README.md).
